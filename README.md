# Exercícios de Lógica de Programação em JavaScript

```
exercicios/
├── index.html      → página para escolher e executar os exercícios
├── executar.html   → página que roda o exercício escolhido
├── faccat/         → 55 exercícios do PDF: ex03.js ... ex85.js (número da apostila)
└── manzano/        → 61 exercícios do txt: L01A.js ... L05K.js
```

## Como executar

1. Abra o arquivo `index.html` no navegador (Chrome, Edge, Firefox...).
2. Escolha o exercício na lista e clique em **Executar**.
3. Responda as perguntas nas caixinhas (`prompt`); os resultados aparecem na página
   (e também no console, tecla F12).

Os scripts usam só `var`, `prompt()`, `console.log()`, `if`, `while`, `do...while` e `for`,
por isso precisam rodar no navegador.

## Nomes dos arquivos

- **faccat/exNN.js**: NN é o número do exercício na apostila.
- **manzano/LxxY.js**: `L01A` = lista 01, item "a".
  - L01_COMPL_A a C: bloco "1)" que vem depois do "7)" no txt (sem nome definido).
  - L02: condicionais | L03: enquanto (`while`) | L04: repita (`do...while`) | L05: para (`for`).
